# Afterglow — цифровые капсулы времени

Сохраняет сообщение с паролем и проверяемой на сервере датой открытия.

**Тип:** Самостоятельный портфолио-проект. Рабочая демонстрационная реализация; коммерческий запуск и использование реальными пользователями не заявляются.

## Что работает
- Создание и список капсул, открытие по паролю после заданной даты.
- AES-256-GCM, scrypt, случайные salt и IV.
- Скрытие шифротекста из публичного API.

## Стек
JavaScript, Node Crypto, Express, SQLite, Zod, HTML, CSS.

## Запуск и проверка
Node.js 24 и pnpm 11.

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm start
```

## Технические решения
- Дата проверяется сервером; неправильный пароль и преждевременный доступ получают разные статусы.
- Тестовые будущие даты вычисляются относительно времени запуска.

## Границы готовности
- Это серверное шифрование, а не end-to-end: сервер видит сообщение и пароль во время запроса.
- Владелец инфраструктуры технически может менять время/код и имеет доступ к хранилищу; интерфейс не доказывает невозможность раннего открытия.
- Нет аккаунтов, лимитов перебора пароля, восстановления доступа и уведомлений. Использовать с демонстрационными сообщениями.
