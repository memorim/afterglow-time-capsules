# Afterglow — цифровые капсулы времени

Сервис цифровых капсул времени. Сообщение шифруется, хранится до выбранной даты и открывается только правильным паролем после серверной проверки срока.

## Инженерные особенности

- AES-256-GCM с уникальными salt и IV для каждой капсулы;
- ключ получается из пароля через `scrypt`, пароль не хранится;
- публичный API никогда не возвращает ciphertext, IV или auth tag;
- преждевременное открытие блокируется HTTP-статусом `423 Locked`;
- SQLite, Zod и интеграционные тесты;
- адаптивный интерфейс с countdown-состояниями.

Две открытые demo-капсулы используют пароли `light` и `orbit` — подсказки отображаются в интерфейсе.

## Запуск

```bash
pnpm install
pnpm start
```

Откройте `http://localhost:4800`. На Windows доступен `start-local.cmd`.

```bash
pnpm test
```

## Текущий режим работы
Шифрование выполняется на сервере: это AES-256-GCM, не end-to-end. Сервер получает пароль и текст запроса. Развёртывание требует ограничения доступа и попыток ввода пароля; аккаунты и восстановление доступа в текущий сценарий не входят.
